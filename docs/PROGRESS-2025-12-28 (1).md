## 5. Database Export Script

### Script Baru

Created `prisma/export-database.ts` untuk export database PostgreSQL ke SQL file.

### Fitur

- Export semua tabel: Users, Technicians, Services, Products, RentalItems, Mitras, Articles, Orders, Reviews, Payments
- SQL file dengan `INSERT ... ON CONFLICT DO NOTHING` (safe untuk import berkali-kali)
- Automatic timestamp pada filename

### Cara Penggunaan

```bash
npx ts-node prisma/export-database.ts
```

### Output

- File: `database-exports/affiliate_gadget_export_2025-12-27T19-56-52.sql`
- Ukuran: ~9.4 MB

### Import Instructions

```bash
# 1. Create database
createdb affiliate_gadget

# 2. Run migrations
npx prisma migrate deploy

# 3. Import data
psql -U postgres -d affiliate_gadget -f database-exports/affiliate_gadget_export_*.sql
```

### File yang Dibuat

- `prisma/export-database.ts`
- `database-exports/*.sql`
