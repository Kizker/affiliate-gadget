## 📊 Data Flow

### Reports Page - Top Selling Products:

```
API Endpoint: /api/admin/reports
↓
Fetches OrderItems with products
↓
Groups by productId
↓
Calculates: totalSold, revenue, stock
↓
Returns top 5 products
↓
Frontend displays with empty state handling
```

### Export Functionality:

```
User clicks Export button
↓
Sets exporting state
↓
Calls /api/admin/reports/export
↓
Downloads file (XLSX/CSV)
↓
Resets exporting state
```
